# Bank Widget Project

## Домашнее задание 17.1

В проект добавлена обработка исключений для товаров и категорий.

### Новая функциональность

- При создании товара с нулевым количеством вызывается ошибка `ValueError`.
- Текст ошибки:
  `Товар с нулевым количеством не может быть добавлен`
- В классе `Category` добавлен метод `middle_price`.
- Метод `middle_price` считает среднюю цену всех товаров в категории.
- Если в категории нет товаров, метод возвращает `0`.
- Добавлены тесты для новой функциональности.

# Bank Widget Project

## Домашнее задание 16.1

В проект добавлены классы-наследники базового класса `Product`:

- `Smartphone` — класс для смартфонов;
- `LawnGrass` — класс для газонной травы.

### Smartphone

Для класса `Smartphone` добавлены атрибуты:

- производительность (`efficiency`)
- модель (`model`)
- объем памяти (`memory`)
- цвет (`color`)

### LawnGrass

Для класса `LawnGrass` добавлены атрибуты:

- страна-производитель (`country`)
- срок прорастания (`germination_period`)
- цвет (`color`)

### Новая функциональность

- Реализовано ограничение сложения товаров только одного класса.
- При попытке сложить товары разных типов вызывается ошибка `TypeError`.
- Метод добавления товара в категорию принимает только объекты `Product` и его наследников.
- Добавлены тесты для новой функциональности.
- Покрытие тестами превышает 75%.

## Домашнее задание 16.2

В проект добавлены:

- абстрактный базовый класс `BaseProduct`;
- класс-миксин `PrintMixin`;
- вывод информации о создании объекта через `__repr__`;
- наследование `Product` от `BaseProduct`;
- тесты для новой функциональности.

### BaseProduct

Абстрактный класс `BaseProduct` содержит общую функциональность для всех товаров:

- метод `__str__`
- метод `__add__`

### PrintMixin

Класс-миксин `PrintMixin` выводит в консоль информацию о созданном объекте и его параметрах.

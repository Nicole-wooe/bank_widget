# Интернет-магазин (e-commerce)

## Описание

В рамках данного задания реализована базовая структура интернет-магазина с использованием объектно-ориентированного программирования (ООП).

## Реализовано

* Класс `Product` (товар)

  * название
  * описание
  * цена
  * количество на складе

* Класс `Category` (категория товаров)

  * название
  * описание
  * список товаров

* Атрибуты класса `Category`

  * `category_count` — количество категорий
  * `product_count` — общее количество товаров

* Реализован автоматический подсчёт количества категорий и товаров

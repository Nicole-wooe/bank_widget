## Новая функциональность

Добавлены функции для работы с банковскими операциями:

- `process_bank_search(data, search)` — поиск операций по строке в поле `description` с использованием регулярных выражений.
- `process_bank_operations(data, categories)` — подсчет количества операций по категориям с использованием `Counter`.
- `main()` — пользовательский интерфейс для выбора файла, фильтрации и вывода транзакций.
